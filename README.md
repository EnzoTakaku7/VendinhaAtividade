# Vendinha — Sistema de Controle de Dívidas
Aplicação desenvolvida em C# com Windows Forms e PostgreSQL para gerenciar clientes e suas dívidas.
Funcionalidades
- Cadastro, edição e exclusão de clientes
- Validação de CPF
- Cadastro e pagamento de dívidas
- Pesquisa, paginação e ordenação por valor devido

Tecnologias utilizadas:
- C#
- NET 8
- Windows Forms
- PostgreSQL
- Npgsql

Como executar:
Configurar o banco PostgreSQL com o arquivo Banco.sql, executar o script SQL e iniciar a aplicação pelo Visual Studio no arquivo DeskTop.
